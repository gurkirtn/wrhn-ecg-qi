# Security and privacy

The repository and public demo must contain synthetic data only. Never commit
names, dates of birth, medical-record numbers, raw exports, credentials, access
tokens, or real ECGs.

A production implementation requires organizational identity, role-based
authorization, encrypted storage and transport, retention controls, immutable
audit logging, security review, and applicable privacy/legal approvals. The
mock login and local state in this repository provide none of those controls.
